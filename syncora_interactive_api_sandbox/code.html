POST /v1/auth/token

Generate Access Token

Exchanges client credentials or an authorization code for an OAuth 2.0 access token. This token is required to authenticate requests to the Syncora API. See {{DATA:DOCUMENT:DOCUMENT_134}} for our comprehensive authentication strategy and lifecycle management details.

Request Body

Parameter Type Description
grant_type Required string Must be set to client_credentials.
client_id Required string Your application's unique identifier.
client_secret Required string Your application's secret key. Keep this secure.

Response

A successful request returns a JSON object containing the access token and its metadata.

200 OK 
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "Bearer",
  "expires_in": 3600,
  "scope": "read:users write:academic"
}
